# XAIVON Website

Production website for XAIVON — AI Infrastructure & Business Automation.

## Tech Stack

- React 19 + Vite 8
- React Router 7
- Vercel (hosting + serverless functions)
- Resend (transactional email)
- Upstash Redis (rate limiting)
- Google Analytics 4
- Vercel Analytics + Speed Insights

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deployment

Push to `main` branch. Vercel auto-deploys.
